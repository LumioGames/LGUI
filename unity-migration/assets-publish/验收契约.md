# 最终背包源 → Unity 资源发布验收契约

本契约先于本轮发布执行建立。只消费已经完成网页保存/导出/DOM回读的最终源，不使用初轮toolchain-test工程作为资源输入。

固定输入：`验证/闭环验证/roundtrip-final/project/Inventory.fairy`。关联导出档案从同目录上级 `publish-report.json.sourceArchive` 只读取得，实际SHA256必须等于该报告及已验收值 `183e93d11990ef2a1adeb8a7329911db525463f55a3eac640c812c2245d0e702`。

执行前置与验收：

1. 仅使用既有OpenFairyGUI core/functions 0.7.0和已安装Sharp；不安装软件或依赖。正式Node source validation必须返回valid、complete=true。
2. 固定包Inventory/invtest1；组件Btn/button01、ItemRow/itemrow1、Main/main0001、Reward/reward01；图片icon/icon0001。源Main.title必须是“旅者背包 · 网页保存闭环”、位置(46,29)、颜色#8df0c4。
3. 全部源工程文件在发布前后逐文件SHA256完全相同；源ZIP前后SHA256完全相同。验证ZIP所有文件与回读工程提取文件逐字节相符。该项包含目标和所有非目标内容，不仅比较文案。
4. 在只读加载的内存Document上选择Unity项目类型，明确输出bytes、compressed=false；关闭插件发现/执行与代码生成。不得写回源.fairy、源设置或源XML。保留明确的原Layabox设置与本轮Unity参数记录。
5. 输出须为正式Unity描述 `Inventory_fui.bytes` 与自制图片产生的图集 `Inventory_atlas0.png`，所有文件真实存在、长度与发布manifest一致，记录SHA256。检查描述magic/version/compressed标记；压缩标记必须false。
6. 用正式BinaryReader再读取Unity描述，核对包/组件/资源ID、Main标题/颜色/坐标、节点引用、列表defaultItem、state页与gears、enter动效有效时间及布局；记录与源工程受支持运行语义的比较。二进制不承载的编辑器元数据不伪装可还原。
7. 输出资源可供下一步Unity运行时消费；本脚本成功只证明发布与二进制语义回读，不证明Unity Editor/IL2CPP运行通过。不把C#代码生成当TS/PuerTS绑定，本轮codeGeneration=false。

允许写入仅为本目录及 `验证/unity-migration/scripts/publish-unity-assets.mjs`。所有证据输出到本目录。Unity软件/PuerTS安装和实际Player测试由主任务独立执行。
