# 设计与结构编辑检查

共用会话、稳定 ID 和平台边界沿用 维护规则，这里仅记录设计分册特有的检查。

| 症状 | 检查 |
|---|---|
| 新组件不可见 | package.xml 注册、path 和真实文件是否一致 |
| 实例改值无效 | target 与属性种类是否对应；当前命令是否支持该 propertyId |
| 控制器覆写无效 | 导出设置、页 ID/索引区别、默认页与实例保存值 |
| 改尺寸后图框仍小或变形 | relation 的位置/尺寸职责、fill、autoSize 与九宫格切分 |
| 数据标签正确但数值错位 | 逐格核对业务 key，不复制其他面板调用顺序 |
| 组件看着正常但代码绑定失败 | 查本工程绑定规则、节点名称和扩展约定；无通用前缀要求 |
| 动效起播闪现或重开异常 | 延迟前初值、前次残留状态、控制器竞争、生命周期停止 |
| 视觉结构缺项 | 参考中的空态、锁定态、提示、分隔、遮罩是否都有对应实现 |
| 资源风格不一致 | 查同场景现成组件与资产，不靠文件名猜用途 |
| 弹窗双遮罩/偏位 | 宿主框架与组件谁负责居中、局部坐标和遮罩 |
| 废弃资源越积越多 | 先查跨包/代码引用，再处理明确废弃资源；不删除历史证据或未知用途资产 |
| 保存后编辑器又覆盖文件 | 误把在线会话与离线 XML 当成两个并行写入口；停止磁盘写入，回到共用会话 |

关闭任务前逐项区分：源码检查、SDK 校验、保存读回、发布、网页交互、截图审阅、原生运行。不能用其中一种替代其余项目。
